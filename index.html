🗺️ Anatomia unui Cod Python

În Python, indentarea (spațiile de la începutul liniei) face parte din cod. Ea spune cine aparține cui: după fiecare linie care se termină cu : urmează un bloc împins la dreapta cu 4 spații. Liniile verticale mov din blocurile de cod îți arată fiecare nivel. 

class Vrajitoare:                                  # nivel 0: clasa
    def __init__(self, nume):                      # nivel 1: o metodă a clasei
        self.nume = nume                           # nivel 2: corpul metodei

    def spune_salut(self):                         # nivel 1: altă metodă
        if self.nume:                              # nivel 2
            print(f"Salut, sunt {self.nume}!")     # nivel 3: corpul lui if
📦 nivel 0: class 🔧 nivel 1: metodele (def) ⚙️ nivel 2+: corpul metodei, if, for ⌨️ 1 nivel = 4 spații (tasta Tab în editor)

🦇 Polimorfism: același nume, vrăji diferite!

Polimorfismul înseamnă că mai multe clase au o metodă cu exact același nume (aici sperie()), dar fiecare o execută în felul ei. Rescrierea unei metode moștenite se numește method overriding.

👀 Pasul 1: Vezi și înțelege codul

Observă cum fiecare clasă copil rescrie sperie(self) la același nivel de indentare ca în părinte:

class MonstruHalloween:
    def __init__(self, nume):
        self.nume = nume

    def sperie(self):
        print("Un sunet misterios se aude în conac...")

class DovleacVesel(MonstruHalloween):
    def sperie(self):
        print(f"{self.nume} luminează ochii portocalii: Booo-ha-ha! 🎃")

class FantomaSclipitoare(MonstruHalloween):
    def sperie(self):
        print(f"{self.nume} trece prin ușă aruncând sclipici: Uuuuu roz! 👻✨")

Capitolul 3 • Cazanul cu Secrete

🧪 Încapsulare și Punguța cu Bomboane

Încapsularea înseamnă că un obiect își ține datele în propriile „buzunare” (atribute) și își schimbă starea prin metode bine stabilite, de exemplu adunând sau mâncând bomboane.

👀 Pasul 1: Clasa vrăjitoarei cu pungă de bomboane
class MicutaVrajitoare:
    def __init__(self, nume):
        self.nume = nume
        self.bomboane = 0          # starea inițială
        self.puncte_magie = 10

    def colinda(self):
        self.bomboane += 3         # schimbăm starea: +3 bomboane
        print(f"🎃 Trick or Treat! {self.nume} a adunat bomboane!")

    def arunca_vraja(self):
        if self.puncte_magie >= 2:
            self.puncte_magie -= 2     # consumăm magie
            print("✨ Vraja roz a transformat o frunză în fluture!")
        else:
            print("😴 Ești prea obosită, ai nevoie de odihnă!")

    def mananca_bomboana(self):
        if self.bomboane > 0:
            self.bomboane -= 1
            self.puncte_magie = min(self.puncte_magie + 2, 10)
